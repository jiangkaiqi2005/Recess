# 课程平台按“学期 + 课程名”归属

一门课在一周内的多个时段，在数据里是多条独立的课程记录，教务导入时也是这样拆分的。如果把课程平台挂在每条课程记录上，用户就得给同一门课的每个时段各填一遍。所以课程平台按“学期 + 课程名”归属：同一学期里同名的课程共享同一组平台。修改课程名时，平台跟着迁移到新名字下。

## Considered Options

- **挂在每条课程记录上**：和现有的“备注”字段一样。这样实现最简单，但会让用户重复录入，这正是 issue #1 想解决的问题。
- **按“课程名 + 教师”归属**：可以区分同名的不同课程（例如两门都叫“体育”），但教务数据里的教师名经常缺失或写法不一致，反而会把同一门课拆散。

## Consequences

- 同一学期里同名但实际不同的两门课，会共享平台。用户需要给其中一门改名来区分。
- 数据库版本从 1 升到 2，并新增课程平台表。JSON 备份和 JSON 导入都要带上课程平台。
