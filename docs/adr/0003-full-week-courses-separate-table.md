# 整周课单独建表，不放进课程表

教务系统里有一类课只有周次，没有星期和节次，例如「操作系统课程设计 [17周]」「硬件综合设计 [18-20周]」，重庆大学的课表把它们放在底部的「整周」行。以前导入时它们因为缺少节次被跳过，这几周的课表就显示「本周暂无课程」。

我们把这类课建模为**整周课**（`FullWeekCourse`），单独存放在 `FullWeekCourses` 表里，字段只有课程名、教师、教室、周次、颜色和备注。周视图在星期表头下方加一行「全天」，本周的每门整周课各占一条横跨 7 列的色条；今日课程把它们排在最前面。

## Considered Options

- **在 `Courses` 表加「整周」标记，星期和节次填占位值**：不用新建表，删除学期、替换导入时会自动一起清掉。但 `Course.dayOfWeek`、`startSection` 在 100 多处代码里被当作真实时段使用（课前提醒、小组件课次、冲突检测、今日课程、课程钟点），每一处都要记得先排除整周课，漏掉一处就会出现「周一 08:00 上课」这样编出来的时间。
- **导入时展开成周一到周五、全天节次的普通课**：完全不用改数据结构，但同一周的两门整周课会互相盖住，也会盖住同周的普通课，小组件和课前提醒还会提醒一个不存在的上课时间。用 HTML 原型对比后放弃。
- **把星期和节次改成可空**：类型上最准确，但同样要改动所有使用这些字段的代码，改动面和第一种一样大。

## Consequences

- 现有课程相关逻辑不需要改动：整周课不会出现在 `Course` 列表里，提醒、小组件、冲突检测天然不受影响。
- 凡是按学期整体处理课程的地方都要同时处理整周课：删除学期、替换导入、合并导入、备份导出与恢复。新增这类功能时要记得这一点。
- 整周课目前只能通过教务导入产生，详情里只能查看和删除；手动新建、编辑以及桌面小组件显示尚未实现。
- 导入中间表示 `ImportCourse` 用 `fullWeek` 标记整周课，此时星期和节次为 0，只能转换为 `FullWeekCourse`，并且不参与冲突判断。
