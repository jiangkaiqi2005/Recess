# 桌面小组件使用 App 预先算好的课次

小组件需要在用户不打开 App 的情况下，跨过零点、下课时刻仍然显示正确的课次。我们的做法是：App 每次刷新小组件时，把本学期剩余的全部课次（课程名、颜色、地点，以及按本地时间记录的起止时刻）一次性写入 `home_widget` 的数据通道。原生端只做两件事：按当前时间挑出要显示的课次，并用不精确闹钟在下一个上课或下课时刻刷新自己。周次、节次时间、课程钟点这些课表规则只在 Dart 里实现一份。

## Considered Options

- **后台运行 Dart 重新计算**（WorkManager 或 `home_widget` 的后台回调）：数据始终是最新的，但需要在后台启动 Flutter 引擎并打开 drift，更耗电，也更容易被国产 ROM 杀掉。
- **在原生端重新实现课表规则**：可以不预先计算，但周次、手动当前周、课程钟点等规则要用 Kotlin 再写一遍，两份实现迟早会不一致。
- **精确闹钟**：上下课时刻能准点切换，但 Android 12 及以上需要用户手动授予权限，而晚几分钟切换对课表来说可以接受。

## Consequences

- 一学期最多几百条课次，数据量在几十 KB 级别。
- 预先写入的课次只反映写入那一刻的课表和当前周。之后对课表的任何修改，都必须经由 App 重新写入。
- 手动设定的当前周会被原样带入未来日期（所有未来日期都算作同一周），小组件在这一点上与 App 主页保持一致。
