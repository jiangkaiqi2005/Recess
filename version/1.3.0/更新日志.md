# Recess v1.3.0 更新日志

## 应用改名为 Recess

- 应用由「Hormone 课表」改名为 Recess，使用新的包名 `io.github.jiangkaiqi2005.recess` 和独立签名。
- Recess 是一个新应用，不能从 Hormone 覆盖升级，两者可以同时安装。迁移课表请先在 Hormone 里导出备份，再在 Recess 中恢复。
- 之后的版本从 Recess 的 GitHub Release 检查更新。

## 课表主页

- 标题显示今天的日期和正在查看的周；点开标题菜单可以跳到指定周、回到本周或修改当前周。
- 去掉学期选择器、切周栏、学期进度条和右下角按钮，添加课程移到顶栏。
- 周视图去掉网格线，课程改为实色圆角色块，只显示课程名和教室；顶栏更矮，时间轴更窄，月份居中。
- 课程采用冷暖平衡的新配色，课表、编辑页、搜索详情和桌面小组件显示一致；已有课程不需要重新导入。
- 开学前或学期结束后，标题不再显示「第 0 周」之类的后缀，也不再出现「回到本周」。
- 翻页更流畅，切换周次后保留纵向滚动位置。

## 课程平台

- 可以为每门课记录课程平台（如学习通、雨课堂、课程群）和链接。
- 在课程详情里点开链接会跳转到外部应用，长按可复制；在编辑页可以增删改平台。
- 平台按学期和课程名保存，改课程名时平台会跟着迁移；备份和恢复会包含平台。
- JSON 导入时，预览里取消勾选的课程不会再写入平台。

## 重庆大学导入

- 导入的课程现在带有教师，点开课程详情可以看到「教师」一行。
- 修复课表页上的教师详情被误当成实验课、计入「无法识别星期」的问题。
- 选择重庆大学时提示校外需先连接校园网或 aTrust VPN。
- 安装后请重新进入重庆大学教务页面导入一次课表，已有课程才会补上教师。

## 其他修复

- 课程详情面板里的提示显示在弹层上方，不再被挡住。

## 版本与升级

- Android 版本号为 `1.3.0+26`，最低支持 Android 7.0（API 24）。
- 数据库新增课程平台表，旧数据会自动迁移。

## 下载

- 不确定手机架构时请选择 `recess-v1.3.0-android.apk`（通用包）。
- ARM64 手机可选择 `recess-v1.3.0-arm64-v8a.apk`；ARM32 手机选择 `recess-v1.3.0-armeabi-v7a.apk`。
- `recess-v1.3.0-x86_64.apk` 用于 x86 64 位 Android 设备及模拟器。
- `.aab` 不能直接在手机上安装；`.sha256` 是对应 APK 的完整性校验文件。
